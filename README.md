# Smart Expense Tracker

A Python-based desktop application for managing daily expenses.

## Features
- Add Expense
- Delete Expense
- Live Search
- CSV Export
- Pie Chart Analytics
- SQLite Database

## Technologies Used
- Python
- Tkinter
- SQLite
- Matplotlib
